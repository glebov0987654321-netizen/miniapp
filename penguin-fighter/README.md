# Penguin Fighter

PvP-файтинг для платформы [Яндекс Игры](https://yandex.ru/games). Отряд пингвинов-спецназовцев против кубических шахтёров. 10 уровней, монеты, магазин скинов и прокачек, босс на финальном уровне.

## Стек

- Чистый HTML5 + Canvas 2D, без сборщиков. Достаточно положить папку в ZIP и загрузить в консоль разработчика.
- Yandex Games SDK v2 (`/sdk.js`) с моком для локальной разработки.
- Локализация: русский и английский (определяется через `ysdk.environment.i18n.lang`).
- Все спрайты рисуются процедурно canvas-примитивами — нет ни одного PNG/JPG ассета.
- Звуковые эффекты сгенерированы через WebAudio API.

## Структура

```
penguin-fighter/
├── index.html         # каркас + DOM HUD/меню
├── style.css          # стили UI и адаптив под мобилки

│   ├── sdk.js         # обёртка над YaGames + мок

│   ├── shop.js        # магазин (скины, апгрейды)
│   └── game.js        # стейт-машина и игровой цикл

```

## Реклама (через Yandex Games SDK)

| Тип | Когда показывается | Метод SDK |
|-----|--------------------|-----------|
| **Fullscreen** | Между уровнями (после нажатия «Дальше») | `ysdk.adv.showFullscreenAdv()` |
| **Rewarded video** | По кнопке «×2 монеты» на экране победы и «Продолжить» на экране поражения | `ysdk.adv.showRewardedVideo()` |
| **Sticky banner** | В меню, магазине и на экранах между раундами; прячется во время боя | `ysdk.adv.showBannerAdv()` / `hideBannerAdv()` |

Все вызовы обёрнуты в `src/sdk.js`. Если SDK недоступен (локальный запуск), показывается визуальный мок (см. `showAdMock` / `showBannerMock`), чтобы тестировать поведение без публикации в Яндекс Игры.

## Локальный запуск

```bash
cd penguin-fighter
python3 -m http.server 8000
# или
npx --yes serve -l 8000 .
```

Открыть в браузере `http://localhost:8000/`.

> Локально `YaGames` не определён, поэтому SDK автоматически переключается в mock-режим — это нормально и нужно для разработки.

## Сборка ZIP для загрузки в консоль Яндекс Игр

```bash
cd penguin-fighter
zip -r ../penguin-fighter.zip . -x "*.DS_Store" "README.md"
```

Загрузить полученный `penguin-fighter.zip` через https://games.yandex.ru/console/developer → ваша игра → раздел «Загрузка игры» → поле «Архив».

## Что нужно настроить в консоли разработчика после первой загрузки

1. **Платформы**: Десктоп + Мобильные.
2. **Ориентация**: Альбомная.
3. **Языки**: Русский, Английский (оба уже поддерживаются в коде).
4. **Возрастной рейтинг**: 6+.
5. **Категории**: «Аркады», «Экшен».
6. **Монетизация**: включить рекламные блоки — Fullscreen, Rewarded video, Sticky banner.
7. **Облачные сохранения**: включить переключатель `Игра использует облачные сохранения`.
8. **Лидерборд** (опционально): создать лидерборд с ключом `main` (имя в коде — `submitLeaderboard('main', ...)`).

## Дебаг

Откройте игру с параметром `?debug-mode=16` в URL — лоадер Яндекс Игр покажет статус инициализации, а наш SDK-wrapper включит подробное логирование в консоль.
